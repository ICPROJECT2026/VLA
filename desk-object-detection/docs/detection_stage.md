> 聚焦范围：只讨论「识别物体」这一步（全检 / 检测），不涉及分类。
> 目标：识别出 object_classification.json 中的 4 个物体（键盘、鼠标、瓶子、褶皱的纸），并且 bbox 位置正确。

|------|----------|
| 名称识别错误 | 纸张被框出来了，但被标成「瓶盖」（bbox [400,398,602,594] 实际框的是纸） |

## 3. 想法 C（原生 grounding）详解

### 3.1 是什么

用 Qwen2.5-VL 原生 grounding 格式输出位置：

- 输出形如：`物品名<|box_start|>(x1,y1),(x2,y2)<|box_end|>`
- 坐标为 **0~1000 归一化**（相对原图宽高），而非自由文本像素坐标。

### 3.2 对「位置准确」的帮助

grounding 的坐标是模型训练中专门对齐的「定位 token」，比自由输出 JSON 像素坐标更稳定、更准，
有望解决「位置漂移」与「像素坐标不准」。

### 3.3 对「名称错误」和「漏检」的作用与局限（需实测）

- **名称错误（纸→瓶盖）**：grounding 主要改善「定位」，对「命名」的帮助不直接。
  但 grounding 输出「名称 + 框」的组合，可能让模型更聚焦「先看对物体、再框位置」，需实测验证。
- **漏检（瓶子）**：grounding 训练的定位能力，可能比开放式 JSON 检测召回更好，但仍需实测。
