# Prompt 版本记录

> 记录每个版本代码中用到的 prompt，便于对比与回溯。
> 模型统一为 Qwen2.5-VL-3B-Instruct，通过 `apply_chat_template` + 图片输入。

## v0.0（detect.py）— 单阶段：检测 + 分类一体

### Prompt 原文

```
请检测这张图片中的所有物品。对每个物品输出以下字段：
- name：物品名称（中文）
- bbox：边界框，格式为 [x1, y1, x2, y2]，其中 (x1, y1) 是左上角，(x2, y2) 是右下角，坐标为像素坐标（以图片实际像素为单位，左上角为原点）
- category：类别，只能是“公共物品”、“私人物品”、“垃圾”三者之一

只输出一个 JSON 对象，不要输出任何其他文字、解释或 Markdown 代码块。格式如下：
{
  "objects": [
    {"name": "物品名称", "bbox": [x1, y1, x2, y2], "category": "类别"}
  ]
}
```

### 说明

- **阶段**：单阶段（检测 + 分类一次完成）。
- **bbox 坐标**：像素坐标。
- **输出格式**：JSON 对象 `{"objects": [...]}`。
- **实测问题**：漏检「褶皱的纸」；「鼠标」被判为私人物品。

## v0.1（detect_v0.1.py）— 二阶段：检测与分类分离

### 阶段 1：检测 prompt（build_detect_prompt）

> 注：`{width}` / `{height}` 实际为图片尺寸 1279 / 1706。

```
请检测这张图片中的所有物品（图片宽度 1279 像素、高度 1706 像素）。要求：
- 准确框出每一个物品，不要遗漏，也不要重复或多报无关物体；
- 对每个物品输出：name（物品名称）和 bbox（边界框，格式 [x1, y1, x2, y2]，(x1, y1) 是左上角，(x2, y2) 是右下角，像素坐标）。

只输出一个 JSON 数组，不要输出任何其他文字、解释或 Markdown 代码块。格式如下：
[
  {"name": "物品名称", "bbox": [x1, y1, x2, y2]}
]
```

### 阶段 2：分类 prompt（CLASSIFY_PROMPT）

> 输入为每个物体裁剪出的局部图（多图打包，一次调用）。

```
请按顺序判断上面每张图片中物品的类别，只能是以下三者之一：
- 公共物品：图书馆等公共场所供公众共同使用的物品（如键盘、鼠标、显示器、饮水机、打印机、桌椅等）
- 私人物品：个人私有的物品
- 垃圾：价值低、可以随意丢弃的物品（如矿泉水瓶、纸团、包装袋、纸巾等，即使完好也算垃圾）

只输出一个 JSON 数组，按图片顺序给出每个物品的类别，不要输出任何其他文字、解释或 Markdown 代码块。格式如下：
["公共物品", "私人物品", "垃圾"]
```

### 说明

- **阶段 1**：只检测（name + bbox），不分类；输出 JSON 数组。
- **阶段 2**：对每个物体裁剪局部图，多图打包一次调用判定类别；输出类别数组。
- **bbox 坐标**：像素坐标。
- **实测问题**：纸张被框出但命名成「瓶盖」；真正的「瓶子」漏检。

## v0.2（拟议）— 意义注入 + 结构化扫描（待落地）

### 完整 Prompt 原文

```
你是一名桌面清洁者。现在你将看到一张桌子上的画面，你的任务是找出桌面上所有需要处置的物品并决定去向：
- 公共物品 → 放归原位
- 私人物品 → 放到失物招领处
- 垃圾 → 扔进垃圾桶

因此任何物品都不能漏掉——包括看起来像垃圾、没有价值的东西，它们同样必须被找到并扔进垃圾桶。

请严格按以下步骤处理图像：

1. 将图像划分为上/中/下或 2×2 区域，逐区域扫描。

2. 在每个区域内，找出所有与局部背景在颜色、纹理、边缘、亮度上存在差异的候选区域，
   特别关注低对比度、小尺寸、被遮挡的目标；不要只看最明显、最大的几个物体。

3. 对每个候选区域给出边界框 bbox，并说明触发依据（颜色 / 纹理 / 边缘 / 亮度）。

4. 判断每个候选区域是否属于一个独立物体；属于同一物体的多个碎片，合并为一个实例。

5. 无法确定类别的，label 填 "unknown"，不要省略不确定项；某个区域存在但无法归类，也要输出 unknown。

以 JSON 列表输出所有实例，不要只输出最明显的几个。格式：
[{"label":"...","bbox":[x1,y1,x2,y2],"evidence":"..."}]
```

### 设计要点

- **意义注入**：桌面清洁者角色，垃圾也必须处置，消除「垃圾可忽略」的偏见。
- **三层约束**：①分区域扫描；②候选区域差异检测 + 碎片合并；③JSON 输出 + unknown 保留。
- **与 grounding 的关系**：后续可将 bbox 改用 0~1000 归一化 / 原生 grounding 格式（待定）。

## v0.3（detect_v0.3.py）— YOLO-World 定位 + Qwen 识别

### 阶段 A：YOLO-World 定位（无 prompt）

- 不 set_classes，使用 YOLO-World 默认行为（默认 COCO 类别，标签仅供参考）。
- 模型 `yolov8s-worldv2.pt`，conf=0.05，按置信度取前 10 个候选框。

### 阶段 B：Qwen 识别 prompt（CLASSIFY_PROMPT）

> 输入：对每个 YOLO 候选框裁剪出的局部图（多图打包，一次调用）。

```
请按顺序判断上面每张图片中的物品，对每张图输出：
- name：物品名称（中文）
- category：类别，只能是"公共物品"、"私人物品"、"垃圾"三者之一

只输出一个 JSON 数组，按图片顺序给出每个物品的结果，不要输出任何其他文字、解释或 Markdown 代码块。格式如下：
[{"name":"物品名称","category":"类别"}]
```

### 说明

- 阶段 A：YOLO-World 定位，召回高、位置准，但默认标签不准（把瓶子标成 clock、纸标成 person），标签仅作参考。
- 阶段 B：Qwen 对裁剪图识别 name + category（多图打包）。
- 实测问题：Qwen 多图识别**数量不足**（6 张图只输出 2 个）、**顺序错乱**。
