# 「垃圾」类别的处理方法 — 探讨

> 范围说明：本文探讨的是目标检测/分类任务中「垃圾」这一类别的识别与归类策略，
> 不涉及物理层面的垃圾回收处理。

## 0. 背景与已确定口径

当前任务用 Qwen2.5-VL-3B 对图片做目标检测，把物品分为三类：公共物品、私人物品、垃圾。

### 已确定的口径（本次确认）

1. **垃圾的评判标准 = 价值**（是否「可以随意丢弃」），与物理状态无关：
   - 价值低、扔掉也没关系 → **垃圾**（即使完好，如满的矿泉水）；
   - 价值高、不能随意扔 → **非垃圾**（即使破损，如坏的金表）。
2. **容错偏好**：
   - 分类误判：容忍度高（分类错误可接受）；
   - 检测召回：要求**准确**（不漏检，但也不多报/误报，不做「宁多勿漏」）；
   - → 总体策略：**检测求准，分类从宽**。
3. **公共物品的判定基准**：以「图书馆」为当前基准（供公众共同使用的物品），但**书籍除外**（场景中不会出现图书馆的书籍）。
   - 正式公共物品清单后续提供；当前先用**临时替代清单**（见下方「临时公共物品清单」），后续替换。
4. **推理预算**：以**时间**为基准，最多 3 轮；把 `detect.py` 的一次完整推理（模型加载 + 推理）视为 **1 轮**。
5. **场景说明**：`6.jpeg` 并非真实图书馆，而是对现实场景的一次**简单模拟**；后续会逐步增加物体数量与噪音（干扰）。

### 临时公共物品清单（占位，后续替换为正式 list）

基于「图书馆基准、书籍除外」，暂罗列如下（可编辑）：

- 键盘、鼠标、显示器、电脑主机
- 桌椅、书架（不含书籍）
- 饮水机、打印机、复印机、扫描仪
- 台灯、插座/排插、笔筒、订书机
- 白板、投影仪

> 该清单为临时替代，等正式 list 给出后直接替换；书籍不会出现，无需考虑。

### 该口径带来的连锁影响

- 「价值」是抽象概念，非像素直接可见，模型需要「物体识别 + 常识价值判断」。
- 价值标准会**改变既有分类**：如「矿泉水/瓶子」价值低 → 应归**垃圾**（此前映射为「私人物品」）；「金表」即使坏 → 仍归**私人物品**。
- 价值高低的边界是主观的，「可随意丢弃」的阈值因人/因物而异，需固化判定标准。

## 1. 为什么「垃圾」难处理

| 难点 | 说明 |
|------|------|
| 价值抽象 | 「价值」不是视觉可见属性，依赖物体身份 + 常识判断 |
| 形态多样 | 纸团、包装、瓶盖、果皮……无固定外观，易漏检 |
| 价值边界主观 | 多便宜算「可随意丢弃」？边界不统一 |
| 样本稀少 | 预训练模型对「低价值物品/垃圾」的 grounding 偏弱 |

## 2. 核心难点拆解（按优先级）

1. **检测准确难（最关键）**：既要检出所有物体（不漏），也要保证框与数量准确（不错），难度最高。
2. **价值判定难**：找到后，需判断其价值是否低到「可随意丢弃」（分类可放宽）。
3. **口径一致难**：价值边界主观，需在 prompt / 规则中固化标准（暂搁置，见 §6）。

## 3. 可选处理方案

### 方案 A：价值导向 Prompt（低成本首选）

在 prompt 中明确「垃圾 = 价值低、可随意丢弃」，并给出正/负例：

- 垃圾（低价值）：矿泉水、饮料瓶、纸团、包装袋、瓶盖、纸巾、一次性用品……
- 非垃圾（高价值）：键盘、鼠标、手机、手表、钱包……

**优点**：改动小、零成本；**缺点**：小目标仍可能漏检。

### 方案 B：二阶段「先检全、再分类」（准确召回）

- 阶段 1：让模型只检测**所有**物体（不分类），尽可能全部检出（不漏也不多报）；
- 阶段 2：对每个物体裁剪出局部图，再单独判断「价值 / 类别」。

**优点**：召回高、判定细；**缺点**：多轮推理、耗时翻倍。

### 方案 C：价值映射表（规则化）

模型只负责「检测 + 报名称」，类别按**价值映射表**归类：

- 低价值清单（矿泉水/纸团/包装/瓶盖/纸巾…）→ 垃圾
- 高价值清单（键盘/手机/手表/钱包…）→ 公共 / 私人

**优点**：稳定、可解释；**缺点**：需维护映射表，名称报错会连锁出错。

### 方案 D：排除法（垃圾 = 全部 − 公共 − 私人）

- 先报出**所有**物体；
- 排除判定为公共/私人的，**剩余兜底归为垃圾**。

**优点**：垃圾变兜底类别，规避价值边界难；**缺点**：漏检仍存在。

### 方案 E：多轮采样 / 集成（投票确认，≤3 轮）

- 多次推理（最多 3 轮）后对检测结果做**投票/去重**，而非简单取并集（避免多报/误报）；
- 类别投票（误判容忍高，投票可放宽）。

**优点**：提升稳定性与准确；**缺点**：耗时、随机性；简单取并集会引入误报，需谨慎。

### 方案 F：外部检测器召回 + VLM 分类

- 用高召回检测器（如 Grounding DINO）先找框，VLM 再做价值/类别判定。

**优点**：召回最稳；**缺点**：引入额外模型，工程复杂。

## 4. 方案对比（按「检测准确」重排）

| 方案 | 检测准确 | 判定 | 成本 | 复杂度 | 契合度 |
|------|----------|------|------|--------|--------|
| B 二阶段裁剪 | 高 | 高 | 高 | 中 | 采用 |
| C 价值映射表 | 中 | 高 | 低 | 中 | 辅助 |
| E 多轮投票 | 中 | 中 | 高 | 中 | 待定 |
| F 外部检测器 | 高 | 高 | 高 | 高 | 待定 |
| A 价值导向 Prompt | 中 | 中 | 低 | 低 | 未采用 |
| D 排除法 | 中 | 中 | 低 | 低 | 未采用 |

## 5. 方案决策（已确定）

结合「检测求准 + 分类从宽」的诉求，方案定为：

1. **当前采用**：B 二阶段裁剪。
   - 阶段 1：先检全所有物体（不分类），尽可能准确检出（不漏也不多报）；
   - 阶段 2：对每个物体裁剪出局部图，再单独判断「价值 / 类别」；
   - 兼顾「不漏」与「不错」，符合「检测求准」；
   - 分类阶段可用 C 价值映射表辅助，误判容忍高，价值判定允许宽松。

2. **待定**：第三步（E 多轮投票去重 ≤3 轮 / F 外部检测器兜底），后续视效果再决定。

**分类从宽**——误判容忍高，价值判定允许宽松，不必在分类上过度投入；
**检测从准**——重点资源放在「准确检出所有物体」上，不做「宁多勿漏」式多报。
